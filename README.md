# Projeto GS-EletroSoluções - Landing Page Residencial

Landing page criada como parte do Desafio 01 do Bootcamp de Desenvolvimento de Soluções Digitais (Kodie Academy). O objetivo é apresentar os serviços elétricos residenciais de forma clara, acessível e semântica.

## 🚀 Sobre o Projeto
O projeto consiste em uma página de apresentação profissional para serviços de instalação, manutenção e revisão elétrica residencial, focada em segurança, qualidade e conformidade com as normas técnicas (NBR 5410).

> "O propósito deste site é conscientizar o cliente sobre a importância de contratar um profissional qualificado, apresentando de forma clara os dispositivos essenciais para garantir a segurança da instalação elétrica, a proteção dos eletrodomésticos e, acima de tudo, a preservação de vidas."

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estruturação semântica e acessibilidade)
- **CSS3** (Estilização, layout responsivo e efeitos visuais)
- **Git** (Controle de versão)
- **GitHub** (Hospedagem do código-fonte)
- **GitHub Pages** (Publicação e hospedagem da página web)

## ♿ Acessibilidade e Semântica
- Uso de tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Hierarquia de títulos correta (`<h1>`, `<h2>`, `<h3>`, `<h4>`).
- Textos alternativos (`alt`) descritivos em todas as imagens.
- Links com atributo `aria-label` para apoio a leitores de tela.

## 🤖 Inteligência Artificial como Parceira
A IA foi utilizada neste projeto para:
- Apoio na estruturação e organização das tags e propriedades de estilização.
- Inclusão de comentários educativos no código-fonte para melhor fixação dos conceitos de programação.
- Elaboração e revisão da documentação (`README.md`).

## 🎤 Pitch do Projeto
1. **O Problema:** Moradores e clientes residenciais muitas vezes enfrentam dificuldades para encontrar profissionais qualificados e confiáveis para pequenos reparos e instalações elétricas seguras, além de não terem conhecimento sobre os dispositivos mais atuais do mercado necessários para uma instalação segura.

2. **A Solução:** Uma landing page direta e acessível que apresenta claramente os serviços prestados, destaca o respeito às normas de segurança, apresenta dispositivos obrigatórios em instalações elétricas que muitos desconhecem e oferece um canal direto de contato via WhatsApp.

3. **O Público:** Moradores, proprietários e pequenos comerciantes que necessitam de manutenção, instalação ou revisão de instalações elétricas.

4. **A Construção:** Desenvolvido em HTML5 semântico e CSS3 puro, com versionamento via Git e GitHub, sem o uso de JavaScript conforme os requisitos do desafio.

5. **O Desafio:** Aplicar corretamente a estrutura semântica do HTML, ajustar layouts com tabelas/cartões no CSS e garantir recursos de acessibilidade (como atributos `alt` e `aria-label`) para que a página seja compreensível para qualquer usuário e leitor de tela.

6. ## 🏷️ Principais Tags HTML Utilizadas

- `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`: Estruturação semântica da página.
- `<h1>` a `<h4>`: Organização hierárquica dos títulos e seções.
- `<ul>`, `<li>`: Listas para navegação do menu e canais de contato.
- `<table>`, `<tr>`, `<td>`: Organização e alinhamento das colunas de serviços e equipe.
- `<img>`: Exibição das imagens com atributos `alt` para acessibilidade.
- `<a>`: Links de navegação interna e botão direto para o WhatsApp.
- `<p>`, `<small>`, `<strong>`: Parágrafos, notas explicativas e destaques de texto.
